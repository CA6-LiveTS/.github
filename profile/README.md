# CA6 LiveTS
Most of the VodTS/LiveTS Chrome extension development was moved to: https://github.com/david-ca6/vodts

## LiveTS-
Repos contain a set of tools to create Timestamps file of YouTube/Twitch streams.  
Chrome extension used to generate Chapter/Timestamp of yt stream.  
The export tool used to export the LiveTs File to ffmpeg format to create chapter in downloaded vod.
  
## StreamTS-
Repos containing LiveTs files of various streams, primarily creators I enjoy watching, are also used as demo files or to test LiveTs Tools.
